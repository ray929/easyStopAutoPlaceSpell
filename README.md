# Easy Stop Auto Place Spell

## English

> Stops newly learned spells from being added to your action bars automatically.

- Newly learned spells no longer place themselves onto your action bars on their own.
- No configuration on purpose: disabling the add-on only takes effect after re-logging (Blizzard's auto-placement tracker is bound to the login session), so there is no in-game toggle.

## 简体中文

> 阻止新学习的技能自动挤进动作条。

- 新学的技能不再自动塞进动作条，由你自己决定放到哪里。
- 不提供游戏内开关（有意为之）：暴雪的自动入条行为绑定登录会话，停用本插件后需重新登录才会恢复。

## 繁體中文

> 阻止新學會的技能自動擠進快捷列。

- 新學會的技能不再自動塞進快捷列，要放哪裡由你自己決定。
- 不提供遊戲內開關（有意為之）：暴雪的自動入列行為綁定登入工作階段，停用本插件後需重新登入才會恢復。

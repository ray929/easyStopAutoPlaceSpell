# Easy Stop Auto Place Spell

> Stops newly learned spells from being added to your action bars automatically.
>
> 阻止新学习的技能自动挤进动作条。

## Features / 功能

- Newly learned spells no longer place themselves onto your action bars on their own.
- 新学的技能不再自动塞进动作条，由你自己决定放到哪里。
